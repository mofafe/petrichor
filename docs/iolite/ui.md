# UI

## 方針

- 初見でも迷わない
- 話していなくても場に居やすい
- UI より空間そのものを主役にする

## Hub

- 参加できる Room の一覧を表示する
- Room ごとの人数、公開状態、ロック状態が分かる
- すぐ入れることを優先し、入力項目は最小限にする
- `public` Room を作る導線を置く

## Room

- Three.js を使った平面空間
- 見た目は 50m x 50m 程度のシンプルなマップ
- ユーザーは 2D 的に移動する
- 各ユーザーの位置がひと目で分かる
- 発話中のユーザーが視覚的に分かる

## Room内UI

- ミュートボタン
- 退出ボタン
- 参加人数表示
- 接続状態表示
- 設定ボタン
- 自分の表示名

## 聞き専でも居やすくする要件

- 入室直後に「どこで会話が起きているか」が見える
- 自分がミュート中であることが常に分かる
- 発話しなくても近づけば聞こえる
- 操作しなくても空間の様子を観察できる

## 表現メモ

- アバターは小さく軽い見た目にする
- リアル寄りではなく、記号的で識別しやすい方向にする
- 誰が話しているかを色やアニメーションで示す
