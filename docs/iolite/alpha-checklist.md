# Alpha 動作確認チェックリスト

## 前提

- server を `:8080` で起動する
- web を Vite で起動する
- 2つのブラウザで同じ Room に入る
- マイク利用を許可する

## 確認項目

- 名前を入力して Room に入れる
- 2ブラウザで同じ Room に入ると相手が表示される
- WASD 移動が相手側にも反映される
- Leave すると相手側から表示が消える
- Mic On でマイク取得できる
- 同じ Room の相手と音声がつながる
- Mic On 中は相手側の表示が発話状態になる
- Mic Off で発話状態が解除される
- 相手に近づくと音量が大きくなる
- 相手から離れると音量が小さくなる

## Alpha 完了ライン

- 同じ Room に2人で入れる
- 相手が見える
- 移動が同期される
- マイク許可後に会話できる
- 距離に応じて音量が変わる
