# Iolite

近づくと声が聞こえる Web VC サービス

## 目的

雑談が自然発生する空間を作る

## MVPで作るもの

- 一時的な Public Room を作れる
- 1部屋あたり最大 6 人まで参加できる
- ブラウザ上でアバターを移動できる
- ユーザー同士の距離に応じて音量が変わる
- ミュート状態と接続状態が分かる

## MVPに含めないもの

- 常設VC
- 課金
- カスタムURL
- テキストチャット
- 複雑なプロフィール機能
