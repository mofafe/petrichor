# Concept

## 一言

近づくと自然に会話が始まる VC 空間

## 解決したいこと

既存の VC は「部屋に入る」と会話の単位が固定されやすい

結果として、次のような状況が起きやすい。

- 1つの会話に入る心理的ハードルが高い
- 聞き専で場に居続けにくい
- 少人数の雑談が自然に分岐しづらい

## 提供したい体験

- 雑談が自然発生する
- 複数の会話が同時に存在する
- 聞き専でも居やすい
- 入退室や移動が会話の流れを壊しにくい

## やらないこと

- SNS 化しない
- 複雑な UI にしない
- 登録を重くしない
- モデレーション機能を最初から広く作り込みすぎない

## 大事な価値観

- 軽い
- すぐ入れる
- 距離感がある

## 体験の基準

- 入室してすぐに「今どこで話しているか」が分かる
- 話さなくても場の空気を感じられる
- 移動すると音の聞こえ方が素直に変わる
- UI を読まなくても数分で使い方が理解できる
