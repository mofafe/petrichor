# Avatar Creation Guide

## 対応形式

- glTF (.glb)
- 将来的にVRM対応予定

## 推奨仕様

- ポリゴン数: 5k〜20k
- テクスチャ: 1024x1024 以下推奨
- アニメーション:
  - Idle
  - Walk
  - Run

## 注意事項

- 著作権を侵害するモデルは禁止
- 極端に重いモデルは禁止
- 公序良俗に反するモデルは禁止

## Blenderからの書き出し

### 推奨設定

- Format: glTF Binary (.glb)
- Apply Modifiers: ON
- Texture: Embed
