# User Guide

Petrichor の現在の公開機能は、ブラウザで使う Iolite ボイス空間です。

## 参加する

1. Petrichor の URL を開く
2. 表示名を入力する
3. Room 名を入力する
4. `Join` を押す

同じ Room 名を入力した人同士が、同じ空間に入ります。

## 操作

- `WASD`: 移動
- `Click`: 視点操作
- `Mic Off` / `Mic On`: マイク切り替え
- `Invite`: 現在の Room URL をコピー
- `Leave`: 退出

## 音声

マイクを有効にすると、同じ Room の参加者と WebRTC で音声接続します。
相手との距離に応じて音量が変わります。

ブラウザからマイク利用の許可を求められた場合は、通話に参加するために許可してください。

## Room

- Room は URL または Room 名で共有できます。
- 現在の最大人数は 6 人です。
- Room が満員の場合は、新しい参加者は入室できません。

## 推奨環境

- 最新の Chrome / Edge / Safari / Firefox
- マイクが利用できる HTTPS 環境

ローカル開発時は `localhost` でもマイクを利用できます。
